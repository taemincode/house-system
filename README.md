# WIS Houses

A website dedicated to the House System of Wrolcaw International School. Created by Taemin Park (MYP5) for Service as Action.

## Features
- House Leaderboard: shows the current points of each house and their rankings.
- House Profiles: provides information about each house, including recent results, house teachers, and house trophies.
- Events: displays upcoming events and activities related to the house system.
- About: provides information about the house system and its purpose.
- Admin Dashboard: allows admins to manage house points, events, and other related information.
